# Introduction
This repository was created as part of the pre-class activity on development environments, modelling tools, and source-control systems. It introduces fundamental concepts used in collaborative software development.
1. Version Control
Version control is a system that records changes made to files over time. It allows developers to track modifications, restore previous versions, and collaborate without losing work.
2. Repository
A repository (repo) is a storage location where a project's files, source code, and version history are maintained. It can be stored locally on a computer or remotely on platforms such as GitHub.
3. Commit
A commit is a recorded snapshot of changes made to a repository. Each commit has a unique identifier and a message describing the changes.
4. Branch
A branch is an independent line of development within a repository. It allows developers to work on new features or modifications without directly affecting the main codebase.
5. Merge
Merging is the process of combining changes from one branch into another. It is commonly used when a feature or modification is completed and ready to be integrated into the main branch.
6. Git and GitHub
- Git: A distributed version-control system used to track changes in source code.
- GitHub: A web-based platform for hosting Git repositories and supporting collaboration among developers.
